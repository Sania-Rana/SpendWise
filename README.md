# SpendWise – Student Expense Tracker

SpendWise is a simple and user-friendly personal finance management web application designed especially for students. It helps users track their income and expenses, manage monthly budgets, and understand their spending habits.

## Features

- Add, edit, and delete transactions
- Track total income and expenses
- Set and manage monthly budgets
- Monitor budget usage with a progress bar
- Category-wise spending insights
- Search and filter transactions
- Sort transactions by date and amount
- Export transaction records as CSV
- Dark Mode and Light Mode
- Data saved using Local Storage
- Responsive user interface

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Local Storage

## Getting Started

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Start managing your expenses!

## Project Structure

- index.html – Website structure
- style.css – Styling and responsive design
- app.js – Application functionality
- README.md – Project documentation

## Data Storage

SpendWise uses browser Local Storage to save transactions, budget information, and theme preferences.

## Purpose

This project was developed as a learning project to practise frontend web development, JavaScript programming, DOM manipulation, and data management.
